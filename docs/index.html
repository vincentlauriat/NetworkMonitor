Every connection your Mac is making, in one window.

NetworkMonitor is a free, lightweight network monitor for macOS — every socket, every listener, filtered, exported, and now rendered in Liquid Glass.

The main window — connections grouped by process, sortable by protocol, interface, state, or traffic.

What it does

See what your Mac is really talking to.

A live view of every TCP/UDP socket, backed by the same private NetworkStatistics API macOS itself uses — no kernel extension required.

Live connections

Every established, listening, and closing socket, refreshed automatically and grouped by owning process.

Listening sockets

Spot exactly which processes are holding a port open, on which interface, before anything connects to them.

Filter as you type

Match on process name, path, PID, IP, hostname, or port — the outline view narrows instantly.

Export to JSON

Save the current snapshot — filtered or not — as structured JSON for a report or a second look later.

Command line mode

Run a single scan headless and print JSON to stdout — no window, easy to pipe into other tools.

Liquid Glass UX

Rebuilt for macOS 26 — real glass materials, not painted transparency. More on that below.

macOS 26

Built on real Liquid Glass, not an imitation of it.

The floating controls, the scan overlay, and row selection now use AppKit's actual glass materials instead of hand-painted light/dark bitmaps.

Save, Settings, Expand and Collapse are real NSBezelStyleGlass buttons rendered from SF Symbols. The scan overlay is a genuine NSGlassEffectView, and row selection now follows the system's dynamic tint instead of a hand-branched light/dark gray. This is why the app now targets macOS 26 and later — these materials don't exist on older releases.

Interface

Four buttons, no menus to dig through.

Everything actionable lives in the floating glass control row along the bottom edge of the window.

⌘S · Save
Writes the currently visible connections (respecting any active filter) to a .json file you choose.
Settings
Opens Preferences — auto-refresh, name resolution, and what to hide by default. See the table below.
Expand
Opens every process group at once, so every connection is visible without clicking each row.
Collapse
Folds the outline back down to one row per process.
Filter
Lives in the toolbar's search field — type to narrow the list by process, address, or port.
PreferenceWhat it does
Auto RefreshAutomatically re-enumerates and redraws the connection list on an interval, instead of only on demand.
Resolve NamesReverse-resolves remote IPs to hostnames via DNS. Off trades readability for speed.
Hide Apple ProcessesFilters out connections owned by Apple-signed system binaries, to surface third-party traffic first.
Hide Local ConnectionsDrops loopback (lo*) traffic from the list.
Disable Update ChecksTurns off the periodic check for a newer release (with a manual Check Now alongside it).
Automation

Same data, zero UI.

Run one scan, print the result as JSON, and exit — useful from a script, a cron job, or a support bundle.

$ NetworkMonitor.app/Contents/MacOS/NetworkMonitor -list -pretty -skipApple
// scans once, resolves nothing, prints indented JSON, skips Apple processes
 
$ NetworkMonitor.app/Contents/MacOS/NetworkMonitor -list -names > snapshot.json
// resolves remote hostnames, redirects the compact JSON to a file
-listEnumerate all connections once and print JSON — no window opens.
-namesResolve remote hostnames via reverse DNS before printing.
-prettyIndent the JSON output for readability.
-skipAppleOmit connections owned by Apple-signed processes.
-h / -helpPrint usage and exit.
